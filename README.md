# Anjou-Compiler
Anjou is a transpiled language designed similar to C++ while being a little simpler to write. Even though it’s simpler you do not lose any critical control and it offers the speed of optimized C++.

Anjou was originally going to be named Pear but that name had legal issues with Perl. The name Anjou comes from a type of Pear. Anjou has easier ways to handle pointers and vectors. All pointers are automatically cleaned for you as you type and Anjou is supposed to give maximum control while having as little memory leaks as possible. Thus it is still possible in some instances in which a developer must manually delete a pointer.
